# 多页卡片规划指南

## 什么时候需要多页

当内容超过一张图片能承载的信息量时，拆分成多页卡片：

- **5-9 页**：适合大多数小红书图文
- **3-4 页**：简短清单、快速分享
- **10+ 页**：深度教程、完整攻略

## 页面结构

### 第 1 页：封面 (Cover)

**目的：** 吸引点击，传达核心主题

**元素：**
- 大标题（一句话概括）
- 副标题（可选，补充说明）
- 主视觉图（可选）
- 作者/账号名（可选）

**示例：**
```
标题：30天减脂计划
副标题：从120斤到100斤的真实记录
```

### 第 2-N 页：内容页 (Content)

**目的：** 传递具体信息

**每页只讲一个点：**
- 一个步骤
- 一个观点
- 一个对比
- 一个清单

**避免：** 一页塞太多内容，信息过载

### 最后一页：总结/CTA (Closing)

**目的：** 总结要点，引导互动

**元素：**
- 核心要点回顾
- 行动号召（"关注我"、"收藏备用"）
- 互动引导（"你觉得呢？评论区聊聊"）

## 内容拆分策略

### 教程类
```
Page 1: 封面 - "5步学会XXX"
Page 2: 步骤 1
Page 3: 步骤 2
Page 4: 步骤 3
Page 5: 步骤 4 + 5
Page 6: 总结 + 常见问题
```

### 清单类
```
Page 1: 封面 - "10个必备XXX"
Page 2-4: 每页 3-4 项
Page 5: 总结 + 购买建议
```

### 对比类
```
Page 1: 封面 - "A vs B，怎么选？"
Page 2: 对比维度 1
Page 3: 对比维度 2
Page 4: 对比维度 3
Page 5: 结论 + 适用场景
```

### 故事类
```
Page 1: 封面 - 吸引人的标题
Page 2: 背景/起因
Page 3-5: 经过（每页一个转折）
Page 6: 结果/感悟
```

### 攻略类
```
Page 1: 封面 - "XXX完整攻略"
Page 2: 行前准备
Page 3-5: 每天行程
Page 6: 实用Tips
Page 7: 预算清单
```

## 文案压缩技巧

### 标题压缩
```
❌ 长：我花了30天时间终于完成了这个减脂计划
✅ 短：30天减脂计划
```

### 正文压缩
```
❌ 长：首先你需要准备一个瑜伽垫，然后穿上舒适的运动服，接下来我们就可以开始今天的训练了
✅ 短：准备瑜伽垫 + 运动服，开始训练 ↓
```

### 使用符号和缩写
```
✓ 表示完成/推荐
✗ 表示避免/不推荐
→ 表示结果/方向
+ 表示和/加上
vs 表示对比
```

## 视觉节奏

### 避免单调
不要每页都是相同的布局，交替使用：
- 文字为主的页面
- 图片为主的页面
- 图文混排的页面
- 纯文字金句页面

### 保持一致性
虽然布局可以变化，但保持：
- 配色方案一致
- 字体层级一致
- 边距和对齐方式一致
- 风格调性一致

## 文件命名

多页文件按顺序命名：
```
page-01.html  (封面)
page-02.html  (内容页1)
page-03.html  (内容页2)
...
page-N.html   (总结页)
```

渲染后自动输出：
```
page-01.png
page-02.png
page-03.png
...
page-N.png
```

## 实战示例

### 示例 1：减脂教程（6页）

**Page 1 - 封面**
```
标题：30天减脂计划
副标题：从120斤到100斤的真实记录
背景图：减脂前后对比照
```

**Page 2 - 核心原则**
```
标题：减脂的3个核心
内容：
1. 热量缺口 > 运动
2. 蛋白质摄入要够
3. 睡眠比想象中重要
```

**Page 3 - 饮食方案**
```
标题：怎么吃？
内容：
早餐：鸡蛋 + 全麦面包 + 牛奶
午餐：一拳米饭 + 两拳肉 + 三拳菜
晚餐：减半碳水，增加蔬菜
```

**Page 4 - 运动方案**
```
标题：怎么练？
内容：
周一三五：力量训练 40min
周二四：有氧运动 30min
周六：休息或轻度活动
周日：完全休息
```

**Page 5 - 常见问题**
```
标题：Q&A
Q1: 会不会反弹？
A: 关键看是否养成习惯

Q2: 需要节食吗？
A: 不需要，但要控制总量
```

**Page 6 - 总结**
```
标题：开始行动吧！
内容：
✓ 收藏这篇
✓ 转发给需要的朋友
✓ 关注我，持续分享减脂干货
```

## 工具辅助

渲染多页时，可以批量处理：

```bash
# 渲染单页
node scripts/render.mjs local-tests/my-project/page-01.html

# 渲染所有页（需要自己写脚本或手动执行）
for file in local-tests/my-project/page-*.html; do
  node scripts/render.mjs "$file"
done
```

或者修改 `render.mjs` 支持批量渲染整个目录。
